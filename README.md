# WASEEM MEDICAL PRO — نظام وسيم الطبي

تطبيق Flutter / Android لإدارة المراكز الطبية ومراكز العلاج الطبيعي والتأهيل.

## الوحدات الحالية
- لوحة رئيسية وإحصائيات.
- إدارة المرضى والملف الطبي.
- تسجيل مريض جديد.
- المواعيد.
- الجلسات والباقات مع منع الخصم المكرر.
- الأقسام والخدمات.
- الكادر والموظفون.
- الفواتير والقبض والصرف.
- محرك قيد مزدوج أساسي.
- التقارير وميزان المراجعة.
- مركز الرسائل وفتح WhatsApp/SMS يدويًا.
- إنشاء PDF وطباعة.
- إعدادات المركز والوضع الليلي.
- قاعدة SQLite محلية.

## البناء
بعد رفع المشروع إلى GitHub يمكن تشغيل GitHub Actions أو تنفيذ:
flutter pub get
flutter analyze
flutter test
flutter build apk --release

## ملاحظة
هذا الإصدار محلي Offline-first. لا يعتمد على WhatsApp API مدفوع أو خادم خارجي.
